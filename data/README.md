# Data

- `meprs_released_dataset/`: released MEPRS candidate translations, BLEURT values, reviewer scores, and dimension scores.
- `external_mqm/`: prepared public MQM data used for external validation experiments.
- `latest_model_judge_inputs/`: input pairs used for the July 2026 latest model-judge comparison.

Private credentials, API tokens, and submission-only files are not part of this public data directory.
